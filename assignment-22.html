ASSIGNMENT 22

Multiplication Table Generator

Create an HTML page with a text box, a Print Table button, and a text area to display the multiplication table of an entered number.

Assignment Output & Reference Code

View the working output and explore the source code.

Multiplication Table Generator

Enter a number to print its multiplication table.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Multiplication Table</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <h2>Multiplication Table Generator</h2>

    <input type="text" id="numberInput"
        placeholder="Enter a number">

    <button onclick="printTable()">
        Print Table
    </button>

    <textarea id="tableOutput" readonly></textarea>

    <script src="script.js"></script>
</body>
</html>
body {
    font-family: Arial, sans-serif;
    text-align: center;
    padding: 30px;
    background: #f4f6fb;
}

input {
    padding: 10px;
    width: 220px;
    margin: 10px;
}

button {
    padding: 10px 20px;
    background: #3158b5;
    color: white;
    border: none;
    cursor: pointer;
    border-radius: 5px;
}

textarea {
    display: block;
    width: 250px;
    height: 250px;
    margin: 20px auto;
    padding: 10px;
}
function printTable() {
    const input = document.getElementById("numberInput");
    const output = document.getElementById("tableOutput");

    const value = input.value.trim();
    const number = Number(value);

    if (value === "" || !Number.isFinite(number)) {
        output.style.backgroundColor = "red";
        output.value = "";
        alert("Please enter a valid number!");
        return;
    }

    output.style.backgroundColor = "white";

    let table = "";

    for (let i = 1; i <= 10; i++) {
        table += number + " x " + i + " = " +
                 (number * i) + "\n";
    }

    output.value = table;
}

Important Note

Enter a valid number and click the Print Table button. The multiplication table from 1 to 10 will be displayed in the text area. If the input is empty or invalid, the text area background changes to red and an alert appears.
