JavaScript Functions

Demonstration of Functions with Parameter Passing

Project Demonstration

Explore JavaScript functions by passing parameters, performing calculations and returning values.

Function Demonstration

Enter values to understand parameter passing in JavaScript.

Function Output

Concept Demonstrated:
  • Function: A reusable block of code.
  • Parameters: Values received by a function.
  • Arguments: Actual values passed when calling a function.
  • Return: Sends a result back from a function.
How to test: Enter a student name and two numbers. Select an operation and click Execute Function. The program will pass the entered values as parameters and display the returned result.

script.js

// Function with one parameter

function greetStudent(name) {

    return "Welcome " + name + "!";

}


// Function with two parameters

function addNumbers(a, b) {

    return a + b;

}


// Function for subtraction

function subtractNumbers(a, b) {

    return a - b;

}


// Function for multiplication

function multiplyNumbers(a, b) {

    return a * b;

}


// Function for division

function divideNumbers(a, b) {

    if (b === 0) {
        return "Cannot divide by zero";
    }

    return a / b;

}


// Handle form submission

const functionForm =
    document.getElementById("functionForm");

const result =
    document.getElementById("result");

functionForm.addEventListener("submit", function(event) {

    event.preventDefault();

    // Get input values

    const name =
        document.getElementById("studentName").value.trim();

    const num1 =
        Number(document.getElementById("number1").value);

    const num2 =
        Number(document.getElementById("number2").value);

    const operation =
        document.getElementById("operation").value;


    // Call function with parameter

    const greeting = greetStudent(name);

    let answer;


    // Select function based on operation

    switch (operation) {

        case "add":
            answer = addNumbers(num1, num2);
            break;

        case "subtract":
            answer = subtractNumbers(num1, num2);
            break;

        case "multiply":
            answer = multiplyNumbers(num1, num2);
            break;

        case "divide":
            answer = divideNumbers(num1, num2);
            break;

        default:
            return;

    }


    // Display function result

    document.getElementById("result").innerHTML =
        "<h3>Function Output</h3>" +
        greeting +
        "<br>First Parameter: " + num1 +
        "<br>Second Parameter: " + num2 +
        "<br>Operation: " + operation +
        "<br>Returned Result: " + answer;

    result.style.display = "block";

});
Note: This project demonstrates JavaScript functions, parameter passing, function calls and return values. All operations are performed directly in the browser.
