ASSIGNMENT 17

Dropdown Number Selection

Select Numbers from Dropdown and Append Them to a Text Box

Project Demonstration

Select a number from the dropdown list and click the arrow button to append the selected number to the text box. A maximum of 10 numbers can be added.

Number Selection

Select a number and click the arrow button to add it to the text box.


Numbers Added: 0 / 10

How to test:
  • Select any number from the dropdown list.
  • Click the → button.
  • The selected number will appear in the text box.
  • Repeat the process to add more numbers.
  • A maximum of 10 numbers can be added.

script.js

let count = 0;

function addNumber() {

    let select = document.getElementById("numberSelect");
    let output = document.getElementById("numberOutput");
    let status = document.getElementById("numberCount");

    let selectedNumber = select.value;

    if (selectedNumber === "") {
        alert("Please select a number!");
        return;
    }

    if (count >= 10) {
        alert("Maximum 10 numbers are allowed!");
        return;
    }

    if (count > 0) {
        output.value += ", ";
    }

    output.value += selectedNumber;

    count++;

    status.textContent = "Numbers Added: " + count + " / 10";

    select.value = "";

    if (count === 10) {
        alert("Maximum 10 numbers added!");
    }
}

function resetNumbers() {

    count = 0;

    document.getElementById("numberOutput").value = "";
    document.getElementById("numberSelect").value = "";

    document.getElementById("numberCount").textContent =
        "Numbers Added: 0 / 10";

}
Note: This program uses HTML dropdown lists and JavaScript to append selected numbers to a text area. A counter restricts the user to adding a maximum of 10 numbers.
