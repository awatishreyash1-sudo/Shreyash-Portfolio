Student Registration Form

Create a Student Registration Form and Validate Required Fields, Email Address and Mobile Number Using JavaScript.

Project Demonstration

Fill in the student details and submit the form. JavaScript will validate all required information.

Student Registration

Enter your details to complete registration.

How to test:
  • Enter the student name.
  • Enter a valid email address.
  • Enter a 10-digit mobile number.
  • Select gender and course.
  • Click Register Student.

script.js

document.getElementById("studentForm")
.addEventListener("submit", function(event) {

    event.preventDefault();

    let name = document.getElementById("studentName").value.trim();
    let email = document.getElementById("email").value.trim();
    let mobile = document.getElementById("mobile").value.trim();

    let emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    let mobilePattern = /^[6-9]\d{9}$/;

    if (name === "" || email === "" || mobile === "") {
        alert("Please fill all required fields!");
        return;
    }

    if (!emailPattern.test(email)) {
        alert("Please enter a valid email address!");
        return;
    }

    if (!mobilePattern.test(mobile)) {
        alert("Please enter a valid 10 digit mobile number!");
        return;
    }

    alert("Registration Successful!");

});
Note: This program uses HTML form elements and JavaScript validation. It checks required fields, validates email format and verifies the 10-digit mobile number. Registration is demonstrated on the client side only.
