ASSIGNMENT 16

Fibonacci Series

Display First 10 Fibonacci Terms Using Two HTML Pages

Project Demonstration

Click the Show button to generate the first 10 terms of the Fibonacci series on the second page.

Fibonacci Series Generator

Click below to display the first 10 terms of the Fibonacci series.

How to test:
  • Click the Show Fibonacci Series button.
  • The second HTML page will open.
  • The first 10 Fibonacci terms will appear in a text box.
  • Click Back to return to the first page.

fibonacci-result.html

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Fibonacci Result</title>
</head>

<body>

    <h1>First 10 Fibonacci Terms</h1>

    <textarea id="result" rows="5" cols="40" readonly></textarea>

    <br><br>

    <button onclick="history.back()">Back</button>

    <script>
        let a = 0;
        let b = 1;
        let series = [];

        for (let i = 1; i <= 10; i++) {
            series.push(a);

            let next = a + b;
            a = b;
            b = next;
        }

        document.getElementById("result").value =
            series.join(", ");
    </script>

</body>
</html>

JavaScript Logic

let a = 0;
let b = 1;
let series = [];

// Generate first 10 Fibonacci terms
for (let i = 1; i <= 10; i++) {

    series.push(a);

    let next = a + b;

    a = b;
    b = next;

}

// Display series in textarea
document.getElementById("result").value =
    series.join(", ");
Note: This program uses two separate HTML pages. JavaScript generates the Fibonacci series and displays the first 10 terms in a read-only text area.
