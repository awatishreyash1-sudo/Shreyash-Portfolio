Display All Odd Numbers Between 1 and 100

Write a JavaScript program to display all odd numbers between 1 and 100 on an HTML page.

JavaScript Reference Code 
function displayOddNumbers() {

    let result = "";

    for (let i = 1; i <= 100; i++) {

        if (i % 2 !== 0) {
            result += i + " ";
        }

    }

    document.getElementById("numberResult").innerHTML = result;
}
Note: The modulus operator (%) checks the remainder. If a number divided by 2 gives a remainder of 1, that number is odd.
